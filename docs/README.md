# Docs

- `foundations/`: the written rules of the design system, one file per topic:
  `01-styleguide.md` (tokens, themes, grid, colour, type, spacing, shape, motion),
  `02-modules.md` (every content module and its component rules),
  `03-page-rules.md` (how to build pages and case studies),
  `04-mocks.md` (device frames) and `05-schemas.md` (live SVG diagrams).
  The values themselves live in code: `src/styles/tokens.css` and `src/styles/base.css`.
- Live reference: run the dev server and open `/claudofolio/styleguide/`.
